# 🎮 Zentry Gaming Website

Welcome to the **Zentry Gaming Website**, a cutting-edge, immersive web experience designed for the next generation of gamers. This project features a stunning, high-performance interface with dynamic animations, premium aesthetics, and a beautiful loading state.

![Zentry Hero](file:///home/senpai/.gemini/antigravity/brain/0c90afc8-e868-457d-a854-c91283a96c43/final_page_state_1781020722973.png)

## 🌟 Key Features

- **Premium Loading State**: A custom-built preloader with concentric animated rings and a glowing logo that ensures a smooth entrance while high-quality videos and images load.
- **Immersive Hero Section**: Featuring high-definition background videos and bold typography that captures attention instantly.
- **Dynamic Scroll Animations**: Using modern CSS `animation-timeline`, sections blur and scale gracefully as the user scrolls through the content.
- **Responsive Design**: Fully optimized for desktops, tablets, and mobile devices with a custom mobile-first menu.
- **Hover Transitions**: Interactive cards and buttons with smooth scaling and gradient effects for a premium feel.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure for better SEO and accessibility.
- **CSS3 (Vanilla)**: Advanced animations, gradients, glassmorphism, and responsive layouts without the need for external frameworks.
- **JavaScript (Vanilla)**: Smooth state management, preloader logic, and interactive components.
- **Boxicons**: High-quality vector icons for social links and navigation.

## 🚀 Getting Started

To run this project locally, simply clone the repository and open `index.html` in your web browser.

```bash
# Clone the repository
git clone https://github.com/Senpai7Adim/Gaming-Website.git

# Navigate to the project directory
cd Gaming-Website

# Open index.html in your preferred browser
```
